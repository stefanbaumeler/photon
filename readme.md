## Introduction

Self-hosted, open source photo management, sync and api for developers. Fuck Google Photos

## Features

## App

- Pictures, videos, albums
- Sync from your iOS or Android device
- Show media on a map
- Search for places, dates, people, pets, objects
- Public, password protected or expiring share links
- Partner accounts

## API
- GraphQL and REST
- Permissions
- Resize on request
- Use as image hosting for your web project
